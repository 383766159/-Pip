# Pip

## Subtitle

Gentle 48-second daily practice

## Promotional text

Build a small, private habit with a calm lift-and-release rhythm, local reminders, and a simple daily streak.

## Description

Pip turns one short 48-second session into a clear, repeatable daily ritual.

- Follow eight guided lift-and-release cycles.
- Pause, resume, or cancel whenever you need to.
- See today's completed sessions and your calendar streak.
- Set up to three local reminders, including weekend preferences.
- Use optional haptics, VoiceOver labels, Dynamic Type, and Reduce Motion support.
- Keep your sessions and reminders on your device.

Pip has no account, network service, cloud sync, advertising, HealthKit access, chat, or in-app purchases.
